AI USAGE POLICY - Virtual Coffee Machine Project
===============================================================


---------------------------------------------------------------
1. AI TOOLS USED
---------------------------------------------------------------

- ChatGPT (OpenAI)
- Claude Code (Anthropic) - agentic coding assistant in the IDE / CLI


---------------------------------------------------------------
2. PURPOSE OF USE
---------------------------------------------------------------

ChatGPT
  - Planning the development stages and walking through the project
    requirements.
  - Researching and comparing technologies before committing to them.
  - Explaining concepts and syntax while writing code.

Claude Code
  - Reviewing existing project files against the requirements document
    and reporting mismatches before any code was changed.
  - Researching and comparing technologies, and presenting the
    trade-offs of each option.
  - Applying approved changes to configuration and infrastructure.
  - Writing parts of the source code, and explaining the purpose, the
    syntax and the concepts behind every file.
  - Reviewing code that I wrote myself and pointing out mistakes in it.
  - Writing the project documentation (README.md and this file).

Every technical decision in this project was presented to me as options
with their trade-offs, and chosen by me rather than for me.

Part of the source code was written by me directly. That code was
reviewed, corrected and explained, so the mistakes in it became things I
understand rather than things that were silently replaced.

No AI tool was used to produce work I do not understand. Every change
suggested by an AI tool was reviewed and explicitly approved by me
before it was applied to the repository.
